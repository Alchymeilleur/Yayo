# Yayo - Your Home, Your Way

Yayo is a modern rental platform for the Republic of Congo that connects individuals and businesses to easily publish and rent homes, vehicles, equipment, and other services.

## Features

### User Features
- **Authentication**: Email/password signup, login, password reset
- **Listing Management**: Create, edit, delete rental announcements
- **Photo Gallery**: Upload multiple photos per listing
- **Search & Filters**: Search by keyword, category, city, price, and date
- **User Dashboard**: View listings, messages, statistics, and manage profile
- **Messaging**: Direct communication between users
- **Reviews & Ratings**: Rate and review other users
- **Favorites**: Save listings for later

### Admin Features
- User management
- Listing management and moderation
- Content reporting and flagging system
- Admin dashboard with analytics

## Categories

## Tech Stack
- **Frontend**: React / Next.js
- **Backend**: Node.js / Express
- **Database**: PostgreSQL
- **Styling**: Tailwind CSS
